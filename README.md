# UK APP Scam & Money Mule Risk Intelligence Platform

## Overview

An AI-powered Financial Crime Investigation Platform that simulates UK banking transactions to detect Authorised Push Payment (APP) scams and money mule activity using:

- Machine Learning (XGBoost)
- Explainable AI (SHAP)
- Graph Analytics (NetworkX)
- Geospatial Intelligence (GeoPandas)
- AI Investigation Agent
- Streamlit Dashboard
